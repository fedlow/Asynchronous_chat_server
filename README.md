# Async Chat Server

Асинхронный чат-сервер на Python с использованием `asyncio`.

## Требования

- Python 3.10+
- Внешние библиотеки не требуются (только стандартная библиотека)

## Запуск

### Сервер

python server.py

Сервер слушает 127.0.0.1:8888.

Клиент (в отдельном терминале)

python client.py

Или с указанием адреса и порта:

python client.py 127.0.0.1 8888

Запустите несколько клиентов в разных терминалах для тестирования многопользовательского режима.

Возможности

Многопользовательский чат с широковещательной рассылкой сообщений (broadcast)

Уведомления о подключении и отключении пользователей

Имя отправителя и время в каждом сообщении

Команды чата:

/help — список команд

/users — список пользователей онлайн

/nick <name> — смена ника

/me <action> — сообщение-действие

/file <path> — передача файла (base64)

/quit — выход

Передача файлов (сохраняются в папку downloads/)

Логирование событий в chat.log

Структура проекта

├── server.py     # сервер
├── client.py     # клиент
├── README.md
└── .gitignore
Технологии
Python 3.10+

asyncio — асинхронный TCP-сервер и клиент (StreamReader, StreamWriter)

logging — логирование в консоль и файл

base64 — передача файлов

pathlib, datetime — работа с файлами и временем
